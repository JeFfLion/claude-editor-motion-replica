# 制作记录

## 参考拆解

- 30 秒，900 帧，1280×720，30 fps。
- 米白纸底 #f7f3ea，深褐描边 #302b27，珊瑚角色 #c86d58，薄荷滑杆 #8cc7b8，黄色文字轨 #efd16b，紫色音轨。
- 顶栏、素材/转场/文字面板、中央手机、右侧调整区、下方时间线；中文手写感字体，圆角边框和细微固定种子纹理。
- 0–1 秒小窗口展开；1–5 秒素材进入、夜景；5–9 秒删片、拉面；9–12 秒转场选择；12–15 秒柴犬和文字、撤销；15–20 秒蹦迪、闪光和饱和度夸张调节；20–24 秒缩放、节拍标记；24–27 秒导出碰撞；27–30 秒手机与便签收尾。
- 镜头沿界面做局部缩放和平移。场景切换沿用剪辑预览的素材切换语法，不额外加入不属于参考的商业片转场。

## 工作流

依用户指定查阅 HyperFrames 的构图、文字和转场方法，以 Remotion 组件实现。保留原 Remotion 项目和精确依赖版本，未引入 HyperFrames 原生时钟或 GSAP 驱动。独立仓库只包含本作品，不包含动画库中用户其他作品或已有改动。

## 验证

- 主动画库 npm run check 与 npm run build 通过。
- 已渲染并检查 0、3、9、13、18、22、26、29 秒关键帧；柴犬素材替换为文字出现前的画面，避免文字重复。
- Studio 成功打开 ClaudeEditorReplica，确认 Composition 及素材加载。
- 交付为可预览、可渲染源码；未额外导出 MP4。
